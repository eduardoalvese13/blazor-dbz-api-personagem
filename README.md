# BlazorDbzPersonagem

Aplicação web desenvolvida em **Blazor** (.NET) que consome a [Dragon Ball API](https://dragonball-api.com/) para buscar e exibir os dados de um personagem através do seu ID.

## Funcionalidades

- **Consulta por ID:** Campo numérico para o usuário informar o ID do personagem desejado.
- **Exibição dos Dados:**
  - **Nome:** Nome do personagem.
  - **Planeta de Origem:** Planeta de onde o personagem se originou.
  - **Transformações:** Lista com todas as transformações registradas para o personagem.

## API Utilizada

- **Endpoint:** `https://dragonball-api.com/api/characters/{id}`

## Tecnologias Utilizadas

- **C#** / **.NET**
- **Blazor Web App**
- **HttpClient**
- **Newtonsoft.Json**
